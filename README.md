# Expense Tracker

## Автор Алексей Чулков

## Описание программы

Expense Tracker — это десктопное приложение для учёта личных расходов с графическим интерфейсом на Python (библиотека Tkinter). Программа позволяет:

* добавлять новые расходы с указанием суммы, категории и даты;
* просматривать все записи в виде таблицы;
* фильтровать расходы по категориям и диапазону дат;
* подсчитывать общую сумму расходов с учётом установленных фильтров;
* сохранять данные между сеансами работы (в формате JSON).

Основные особенности:
* интуитивно понятный графический интерфейс;
* предустановленные категории расходов: «Еда», «Транспорт», «Развлечения», «Жильё», «Прочее»;
* автоматическая загрузка и сохранение данных в файл `expenses.json`;
* проверка корректности вводимых данных (сумма, формат даты).

## Как использовать

### Запуск приложения
1. Убедитесь, что на компьютере установлен Python 3.6 или выше.
2. Сохраните код программы в файл с именем `expense_tracker.py`.
3. Откройте командную строку (терминал) и перейдите в папку с файлом.
4. Запустите приложение командой:
   ```bash
   python expense_tracker.py
